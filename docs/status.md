# 当前状态与后续优先级

最后验证：2026-08-02。

## 可用基线

- 普通拼音输入、原文提交、数字选择、页内移动和翻页可用。
- 候选窗定位、150% 缩放、Plasma popup 层级和引擎重启后的快照恢复已修复。
- 候选窗支持午夜蓝、极光绿、云雾白、墨韵和星愿少女主题；星愿少女带原创角色动画，主题、字号、圆角和透明度可在设置页修改并即时应用。
- F8 按住说话可录音，松开后提交一次最终文本；X11 自动重复不会再切出大量短会话。
- 语音 worker 会预先建立暂停的 PipeWire 流并后台加载模型；冷启动时先采集再等待模型，首句不再因模型加载被吞掉。
- 默认 2025 普通话 Zipformer 已在当前 i5-12400F 上验证 RTF 约 0.078；Silero VAD、个人词库热词、modified beam search 和中英标点恢复已接入。
- 已修复个人词条选择次数从未递增的 SQLite 多语句 bug；语音热词现在按类型和真实使用频率筛选、限量、去重，并按所选模型词表剔除无法编码的字符，避免常用单字和 OOV 词污染解码。
- 设置页只列出 manifest 校验通过的本地模型，可在普通话优先与旧中英兼容模型间切换；诊断输出包含设备、模型和 worker 状态且不包含原始音频或识别文本。
- SQLite 个人词库、麦克风选择、快捷键保存和 Fcitx profile 修复可用。
- Debug/Release 在 `-Werror` 下构建通过，默认四项 CTest 全部通过。

总体评价：当前机器上的语音底层可靠性已接近日常可用基线，但在用户口音语料、设备异常和长时间压力测试完成前，仍不能宣称达到可推广的生产验收线。

## 已知不足

- 候选窗无鼠标选择；长候选、分页提示和边缘布局仍需改进。
- 只完成少量真实应用验证，缺少 Qt、GTK、浏览器、Electron、终端和焦点快速切换矩阵。
- 语音尚无完整数字/日期/单位逆规范化，也没有基于 VAD 的免按键自动结束。
- 蓝牙输入仍使用固定软件增益策略；设备重连、source 更名、静音和异常恢复覆盖不足。
- 当前 WH-1000XM3 蓝牙麦克风已由用户现场验证“巴拉拉”可一次识别并最终提交；该会话热启动 5 ms、最终化 9 ms、VAD 命中且无溢出。音频未保存。仍需扩充经授权的多句、多噪声 CER 语料。
- 安装依赖当前机器的 Fcitx 系统插件目录和非交互 sudo；没有 deb 包、CI 或发布流程。
- Wayland、多显示器、动态缩放、GNOME、Flatpak/Snap 和其他发行版未验证。

## 下一步建议

1. 采集经用户授权的本机语音回归集，覆盖短词、长句、中英混说、噪声和口音；把 CER、空结果率和首句成功率作为发布门槛。
2. 完成蓝牙断开/重连、设备更名、静音、100 次连续会话和 30 秒上限压力测试。
3. 在固定语料保护下加入保守的数字、日期和单位逆规范化；评估 toggle 模式的 VAD 自动结束。
4. 建立桌面端到端矩阵，覆盖焦点切换、Fcitx/服务重启、Qt/GTK/浏览器/Electron/终端和 100%/150% 缩放。
5. 增加 CI、许可证清单、可卸载发行包和无需特殊 sudo 配置的安装方式。
