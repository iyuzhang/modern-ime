# 当前状态与下一阶段

最后验证：2026-08-09。

## 本轮结论

当前版本在 Ubuntu 24.04、KDE Plasma 5.27、X11 和 Fcitx5 5.1.7 上达到个人日常试用基线。连续组句与语音标点基线之上，新增了面向开发人员的智能混合输入：中文拼音、开发词原文、代码结构和个人选择历史在同一组合中决策，不再要求日常手动切换中英文模式。

这仍是单机验证过的开发版本，不代表已达到跨桌面、跨设备或可公开推广的生产标准。

## 已验证基线

### 键盘输入

- 默认使用智能混合模式；`git`、`ls`、`ll`、常见低歧义 Shell 命令、高置信开发词、驼峰、字母数字组合、路径、命令参数和代码符号会自动提交并在当前词元内临时英文直通，候选窗随即隐藏。普通拼音仍以中文为首选，中文优先和英文直输保留为显式退路。
- 智能模式下短按 Ctrl 可切换当前输入上下文的临时英文直输，再次短按恢复智能判断；Ctrl 与其它按键组合仍交给应用，失焦/重置恢复智能模式，设置页可关闭此快捷行为。
- 自动直通状态下，`Space` 和 `Enter` 是应用收到的正常边界键，不再承担候选确认；模糊原文首选仍可用一个 `Space` 同时提交词元和实际空格，中文候选保持传统空格选词语义。
- 中英文选择偏好独立于拼音词库，按全局与当前应用分别学习并热更新；普通小写拼音需重复选择英文原文才会形成英文偏好，单次误选不会让 `nihao` 一类输入永久直通；最近一次纠正可以打破历史计数平局，原文不会污染 ASR 热词。
- 启用中英文间距时，提交开发词可根据光标前字符补足中文/英文边界空格；光标周边文本只瞬时用于判断，不持久化。
- libime 解码深度为 32；长拼音没有正确整句时，可逐字或逐词选择，已选内容保留在预编辑区，最后一次性提交。
- 分段组句会学习各段及完整“拼音 → 句子”映射，并通过 D-Bus 热更新运行中的引擎；再次输入相同拼音时，已学习整句位于首选。
- SQLite 个人词库支持自动学习、手动维护、导入导出，并为语音模型生成经过筛选和词表校验的热词。

### 语音输入

- F8 按住说话、松开提交；X11 自动重复、冷模型首句、焦点校验和单次最终提交链路可用。
- 在线麦克风使用预先建立的暂停 PipeWire 流并后台加载识别器、VAD 和标点模型；所选设备离线时不常驻约 670 MB 的 ASR worker。
- 流式候选只在文本变化时、最多每 600 ms 恢复一次内部标点，并隐藏不稳定的末尾标点；最终文本清理标点前空格并保证中文或英文句末标点。
- 运行时不保存音频，诊断信息也不包含识别文本。

### 桌面与工程

- 独立候选窗的 150% 缩放定位、Plasma popup 层级、无焦点显示、引擎重启快照和图形会话启动已验证。
- 设置程序的用户级桌面启动器使用绝对可执行路径，不依赖 KDE 图形会话是否包含 `~/.local/bin`；桌面文件校验和 offscreen 启动检查已通过。
- 候选窗和设置页共有 12 套主题；字号、圆角、透明度和主题可即时更新。
- Debug 与 Release 均在 `-Werror` 下通过 5 项 CTest；部署脚本会在安装前重复执行 Release 测试并备份现有文件。

## 已知限制

- 内置开发词与结构规则不能覆盖所有项目专有标识符；陌生词若同时是合法拼音，首次可能需要用 `Enter` 或候选选择纠正。尚无编辑器插件或工作区符号词库。
- 应用作用域只能使用 Fcitx 前端提供的 program 名称和能力标记；IDE 的代码区、注释区、搜索框和提交信息框未必能被可靠区分，需要真实应用矩阵继续校准。
- 候选窗不支持鼠标选择；长候选、分页提示和屏幕边缘布局仍需改进。
- 真实应用覆盖较少，尚缺 Qt、GTK、浏览器、Electron、终端和焦点快速切换矩阵。
- 语音尚无完整数字、日期和单位逆规范化，也没有基于 VAD 的免按键自动结束；口音、噪声、蓝牙异常和长时间压力测试不足。
- 蓝牙输入仍使用固定软件增益；设备重命名、静音和异常恢复覆盖不足。
- 只验证 X11；Wayland、多显示器、动态缩放、GNOME、Flatpak/Snap 和其他发行版尚未验证。
- 安装仍依赖 Fcitx 系统 ABI 目录和非交互 `sudo`；没有 deb 包、CI 或正式发布流程。

## 下一阶段

下一阶段先在 Konsole、VS Code/Electron、JetBrains、浏览器、Qt 和 GTK 应用中记录不含输入正文的命中原因与纠正计数，校准开发词、上下文权重和边界行为。若规则与个人学习仍不能覆盖项目专名，再设计明确 opt-in 的工作区词库或编辑器插件；不预先引入联网模型，也不扫描源码正文。

后续质量工作保留为待办：授权语音回归集与 CER 门槛、蓝牙异常和连续会话压力测试、真实应用兼容矩阵、数字/日期规范化，以及 CI 和发行包。
